# HALAZIA: The Lost Signal

A 3D sci-fi pirate shooter developed using Unity.

## About the Game

**HALAZIA: The Lost Signal** is a 3D sci-fi pirate shooter inspired by dystopian worlds and the ATEEZ lore universe. The game takes place aboard a multi-level vessel controlled by hostile forces, where the player must fight through different decks, interact with the environment, retrieve a mysterious artifact, and complete the mission.

The game also features autonomous enemies with different behaviours and decision-making strategies, making encounters more dynamic than simply fighting enemies that follow fixed paths.

## Key Features

* **3D Environment:** A multi-level ship with interconnected decks, industrial environments, and atmospheric lighting.
* **Player Interactions:** Shooting, movement, doors, barricades, and throwable objects.
* **Intelligent Agents:** Different enemy behaviours, including patrolling, sound-based investigation, tactical flanking, and coordinated decision-making.
* **3D Modelling:** Custom models, materials, textures, and environmental assets.
* **Dynamic Pathfinding:** AI agents that navigate the environment and adapt to changing situations.
